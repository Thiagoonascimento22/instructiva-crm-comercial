Configurar painel

Coloque o endereço e o código de TV de cada sistema (em cada um: Vendas → Gerenciar → Integrar sistema). Fica salvo neste navegador.

No endereço coloque só até .app. As telas passam sozinhas a cada 25 segundos.
Pra deixar uma TV só numa tela, use no endereço ?tela=ritmo&fixa=1 (ou geral, hoje, semana). TV muito lenta: ?leve=1.
Atalhos: ← → trocar tela · espaço pausar · F tela cheia · + − aumentar/diminuir (ou canal +/− no controle) · 0 volta ao tamanho automático. Se a TV continuar grande demais, coloque ?zoom=0.5 no fim do endereço.
